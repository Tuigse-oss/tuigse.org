Code signing policy

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status

No release is signed yet. We are applying to SignPath Foundation, and this policy describes how signing will work once each project is accepted. Until then, the checksums and build attestations described under Check a download before you run it show that a file is the one the repository built.

What will be signed

The Windows programs and installers of Hivemend, Topos and OpenIRC, and nothing else. Each will be built by its repository's release workflow on GitHub from a version tag, and a maintainer will approve each signing request before SignPath signs it. No third-party program, and nothing built outside those workflows, will be signed under this certificate.

OpenCB Radio runs in the browser, so it has nothing to sign.

Privacy policy

Each of these programs follows this policy:

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

  • Hivemend contains no networking code.
  • Topos contains no network code. See its privacy notes.
  • OpenIRC connects to the IRC servers, proxies and DCC peers you choose. When you click Update in the network directory, it downloads a public list of IRC networks from raw.githubusercontent.com over HTTPS, not through your IRC proxy. Web links and searches open in your browser, and scripts you add can run commands for you. Its ident server is off unless you turn it on, and the program has no telemetry and never checks for updates to itself.

Questions

To report a problem with a signed file, open an issue on the app's GitHub page, or for a security problem follow its SECURITY.md. For anything else, email bwilliamson@tuigse.org.
